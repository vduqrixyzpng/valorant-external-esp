Capabilities

What the loader actually does

✨

Player Glow

Reads entity color data out-of-process and highlights enemy outlines through a memory-mapped glow buffer, with adjustable intensity and visibility checks.

📦

Box ESP

Projects 3D bone positions to 2D screen space and draws bounding boxes with distance scaling, health-tinted borders, and head/body color separation.

🦴

Skeleton Overlay

Full bone-to-bone skeleton rendering using the game's bone matrix offsets — a hands-on lesson in reading transform hierarchies from process memory.

🧠

Memory-Based Loader

External reader/writer using ReadProcessMemory and handle duplication. No DLL injection, no kernel driver — ideal for learning process isolation.

🎯

Aimbot Module

Purely academic target-selection study: FOV gating, bone priority, smoothing curves, and how input simulation is detected by modern anti-cheat.

📚

Fully Documented

Every offset, signature pattern, and overlay routine is explained in the source. Built as a teaching companion for game-security researchers.
