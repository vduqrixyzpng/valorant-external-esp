# Security Policy

## Supported versions

Only the `main` branch is maintained. This project is a **research / educational
artifact** — there is no supported production release.

## Reporting a vulnerability

If you believe you've found a vulnerability *in this repository's code*
(e.g. a path traversal in the offset loader, or a crash in the overlay
renderer), open a private security advisory on GitHub.

Do **not** report Vanguard bypasses or Riot account bans here — those are
out of scope and will be closed.

## Ethical use

This toolkit is provided **for educational purposes only**. Running external
cheats against Valorant violates Riot's Terms of Service and will result in a
HWID ban. The authors take no responsibility for misuse. Use only against
offline training bots or your own test harness when studying.

## Out of scope

- Vanguard kernel bypass discussions
- HWID spoofer source
- Working, up-to-date offsets for the live client
